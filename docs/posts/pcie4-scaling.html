Does PCIe 4.0 remove the prefill bottleneck?

Prefill on this machine waits on expert uploads over PCIe 3.0. The card and the board can do Gen4, the CPU can't. We calculated what a CPU swap would give. Nothing has been measured yet.

This entry is a hypothesis. It was written down before the hardware exists here, so that the measurement can be held against it later.

What we found

The mainboard is a Z590 model. Its x16 slot can run PCIe 4.0, but only with an 11th-generation CPU (Rocket Lake). The i9-10850K in the machine is Comet Lake, and its root port reports a link capability of 8 GT/s. The RTX 3070 is Gen4-capable and runs at Gen3 because of the CPU. Certainty: high, this was read from the hardware.

The estimate

Prefill is bound by uploading experts to the GPU. With the prefetch build most of the compute already hides behind the upload, so the link speed is what is left.

Host to device Upload per micro-batch Micro-batch Prefill, pp4096
Today, Gen3 12.4 GB/s (measured) 1.59 s 1.72 s 2,384 t/s (measured)
Gen4 about 24 GB/s (assumed) about 0.8 s 0.9 to 1.0 s 4,000 to 4,500 t/s (calculated)

After that, upload and compute (about 0.63 s) would be roughly the same size. Certainty: medium. The Gen4 rate of the 3070 is an assumption and has not been measured.

The 2,384 t/s here is a pp4096 measurement. It is not the same condition as the 2,438 t/s for 16k tokens of real text through the server that the other pages quote.

What a swap would mean

  • Candidates are the i9-11900K and the i7-11700K, with 8 cores instead of 10. Generation saturates at 6 threads on this machine (measured), so the thread count has to be measured again.
  • Generation speed should stay the same, because it is bound by RAM. Rocket Lake brings AVX-512 for the CPU expert path. Its effect is not measured.

How it will be tested

  1. Confirm the slot comes up as Gen4 (nvidia-smi --query-gpu=pcie.link.gen.max --format=csv has to show 4).
  2. Measure host-to-device bandwidth with the same tool that gave 12.4 GB/s.
  3. Rerun the pp4096 and 16k prefill measurements with the same build and the same profile.
  4. Rerun generation at the old and the new thread count.

Decision: open. No hardware, no budget. The estimate stays a hypothesis until the measurement exists. Help us run it.
